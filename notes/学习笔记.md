### Lesson 01 · 第一个程序（hello.py）

**学到的概念：**

## 阶段三：Git 与规范（已完成 🎓）

### L9 · Git 本地基础（已完成 ✅ ｜ 2026-11-01）

**核心理念：** Git 是代码的时光机——工作区（你在改）→ 暂存区（挑好了）→ 本地仓库（存了档），随时能翻回任何一张照片。

**核心命令：**
```bash
git init                  # 把文件夹变成仓库（创建 .git 档案室）
git status                # 看状态：红=未跟踪，绿=已暂存
git add .                 # 全部放进暂存区
git commit -m "说明"      # 正式存档（动词开头写清做了什么）
git log --oneline         # 看历史，新的在上面
git diff                  # 看具体改了哪几行（+ 是新增）
```

**配置（一次性的）：**
```bash
git config --global user.name "张双"
git config --global user.email "zhangs0109@163.com"
git config --global core.quotepath false    # 让中文文件名正常显示
```

**踩过的坑：**
- 把邮箱误写进 user.name → 用 `git config user.name` 验证时发现并当场改正（好习惯：敲完必验）
- 中文文件名显示为 \346... 乱码 → core.quotepath false 修复
- **Git 规矩：没有输出 = 一切正常**，只有报错才说话

### L10 · Git 进阶：撤销与排查（已完成 ✅ ｜ 2026-11-04）

**新增掌握的命令：**
```bash
git diff                  # 看【还没 add】的改动
git diff --staged         # 看【已经 add、等着提交】的改动
git restore --staged 文件 # 把文件从暂存区撤回（改动本身保留，代码不会丢）
```

**真实踩过的坑（价值极高）：**
- **嵌套仓库**：在 `exercise/` 里又跑了一次 `git init`（练 L9 时），造成子目录变成独立仓库 → 在子目录 `git push` 报 `No configured push destination`（因为它根本没有远程）

  - 教训：**想练 `git init` 去 `/tmp` 建沙盒，别在真项目里做实验**
- **`git add .` 只管"当前目录以下"**：在 `exercise/` 里执行，就只暂存 exercise 里的文件 → 日常归档改用 `git add -A`（覆盖整个仓库）

## L11 · 虚拟环境与 pip（已完成 ✅ ｜ 2026-11-01）

**解决的问题：** 装第三方库（pandas 等）时不要污染系统 Python，不同项目还能用不同版本。

**核心命令（在项目根目录执行）：**
```bash
python3 -m venv .venv            # 创建虚拟环境（一个独立的小房间）
source .venv/bin/activate        # 进入（macOS/Linux）→ 提示符前出现 (.venv)
pip install pandas openpyxl      # 在这个房间里装库
pip freeze > requirements.txt    # 把装了什么都记账，换电脑能一键复原
deactivate                       # 退出（提示符的 (.venv) 消失）
```

**关键认知：**
- 看到 `(.venv)` 前缀 = 在房间里；没有 = 在系统里（装库会装到系统）
- **虚拟环境和"当前所在目录"无关**，只要激活了就一直在房间里，`cd` 到哪都不影响
- `requirements.txt` 是给"另一台电脑"看的清单：别人拿到项目，`pip install -r requirements.txt` 就能装回一模一样的环境
- `.venv/` 文件夹**不要提交到 Git**（已写进 `.gitignore`）——体积大且与操作系统绑定

## L12 · pandas 数据分析入门（已完成 ✅ ｜ 2026-11-01）

**解决的问题：** 8000 多行的 Excel 台账，用 `for` 循环一行行算太慢太啰嗦，pandas 可以用一两行完成"筛选 + 分组 + 求和"。

**核心概念：把 Excel 表看成一个 DataFrame（数据框）**
```python
import pandas as pd

df = pd.read_excel("物资台账.xlsx", sheet_name="明细", header=2)
#   header=2 → 表头在第 3 行（前两行是标题/单位），必须数准，否则整个表错位
#   注意：.et / .wps 是 WPS 私有格式，pandas 读不了 → 必须先另存为 .xlsx

print(df.head())        # 看前 5 行
print(df.columns)       # 看列名
print(len(df))          # 多少行
print(df["实耗量"].sum())   # 某一列求和
print(df["实耗量"].max())   # 某一列最大值
print(df["实耗量"].idxmax()) # 最大值在第几行（行号索引）
```

**最常用的一招：筛选**
```python
over = df[df["超耗量"] > 0]          # 只留超耗的行
df.loc[df["超耗量"] < 0, "超耗金额"] = 0   # 把负成本行的超耗金额清零（修正口径）
```

**第二招：分组汇总 groupby（L8 字典的工业版）**
```python
grouped = df.groupby(["材料", "部位", "单位"], as_index=False, dropna=False).agg(
    录入笔数=("实耗量", "count"),     # 具名聚合：左边是结果列名，右边是(源列, 算法)
    实耗量=("实耗量", "sum"),
    定额=("定额", "sum"),
    实耗金额=("实耗金额", "sum"),
)
grouped["单价"] = (grouped["实耗金额"] / grouped["实耗量"]).round(2)
```
- `groupby(["材料","部位","单位"])` = 按这三个字段"归堆"
- `agg()` 而不是 `.sum()`，是因为**同一个字段要用不同算法**（数量求和、笔数计数）
- **加权平均价 = 总金额 ÷ 总数量**，不是把每笔单价取平均——这是成本核算的铁律

**第三招：查重**
```python
dup = df[df.duplicated(keep=False)]   # keep=False → 连"第一笔"也标出来，看得全
```

**第三招：导出**
```python
df.to_excel("结果.xlsx", index=False)   # index=False：别把行号写成第一列
```

- `FileNotFoundError`：Bash 工具里 `cd` 不跨命令保持 → 改用 `BASE = os.path.dirname(os.path.abspath(__file__))` 拼绝对路径，脚本放哪都能跑
- DZD 控制值差 1.37 亿：误把某列当成"DZD 合价"，实际是"全部原币合价 + 混币种调遣费" → **口径不明确时不能瞎凑，要逐项还原**
- `agg()` 里加了 `数量=("数量","sum")`：跨单位（KG / 台班 / 月）相加毫无意义 → 删掉。**不是所有数字都能加**
- 列名里混进了 float（`102714685.199807`）→ 用 `str(c)` 包一层再判断

## 踩坑档案（长期有效）

1. **报错不可怕**：读错误信息的最后几行，定位到行号和错误类型。已经打过交道的报错：
   - `can't open file ... No such file or directory` → 文件名打错了（quiz.py11 事件）
   - `ValueError` → 文字转数字失败（guess.py 彩蛋）
   - `TypeError: can only concatenate str (not "float") to str` → 数字和文字用加号拼了
   - `FileNotFoundError` → 数据文件不在"当前工作目录"，不是代码错
   - `No configured push destination` → 这个仓库没配远程（多半是嵌套仓库）
2. **改完必须保存**：不保存运行的是旧代码
3. **亲手敲代码**：肌肉记忆比看懂重要
4. **自己改错一次 = 看十个教程**
5. **数字能加的前提是单位相同**：KG 和台班不能相加，人民币和美元不能相加（先折算）
6. **工具不要替人做业务判断**：发现异常先报告，改不改由人定
7. **算得对不对，靠对拍不靠感觉**：先对控制总额，再谈分析结论
