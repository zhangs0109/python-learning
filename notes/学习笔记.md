## 阶段一：基础语法（已完成）🎓

**时间**：2026-10-28（一天完成，进度超前）

### Lesson 01 · 第一个程序（hello.py）

**学到的概念：**
- `print()`：把括号里的内容打印到屏幕
- 注释：以 `#` 开头的行，写给人看，电脑跳过
- 引号里的内容是"文字"（照着念），没有引号的是"指令"（电脑要理解）
  - `print("2026")` 打印文字 2026；`print(2026)` 打印数字 2026

**遇到的坑：**
- 代码里的括号、引号必须用**英文符号**，中文符号会报错

**开发流程（第一个跑通的循环）：**
写代码 → Command+S 保存 → 终端 `python3 文件名` → 看结果

### Lesson 02 · 变量与输入（me.py）

**学到的概念：**
- 变量：贴了标签的盒子，`name = "张双"` 把东西装进去，之后用名字取用
- `input("提示语")`：让程序停下来等用户打字，用户输入的内容存进变量
- 字符串拼接：`"你好，" + name + "！"`（加号连接）
- print 用**逗号**隔开的内容会**自动加空格**，用**加号**则紧紧相连

**好习惯：**
- input 的提示语结尾留一个空格，用户输入不会挤在一起

### Lesson 03 · 条件判断（quiz.py）

**学到的概念：**
- `if / elif / else`：程序按从上到下顺序检查条件，谁成立走谁的路，都不成立走 else
- `==` 是"判断相等"，`=` 是"赋值装盒子"，千万别混
- 缩进：冒号 `:` 的下一行要缩进 4 格，Python 靠缩进识别"哪些行属于 if"

**验收记录：** 三档分支（输入 2 / 11 / 其他）全部验证通过 ✅

### Lesson 04 · 循环与随机数 → 毕业作品（guess.py）

**学到的概念：**
- `while 条件:`：条件成立就重复执行缩进里的代码
- `while True:` + `break`：无限循环，break 立刻跳出
- `import random` + `random.randint(1, 100)`：随机抽一个 1~100 的整数
- `int(text)`：把文字变成数字（input 拿到的永远是文字）
- `count = count + 1`：计数器，每轮加 1

**毕业验证：** 助手模拟玩家连续猜数，游戏正常提示大小、报出答案和猜测次数 ✅

### Lesson 05 · 异常处理（已完成 ✅）

**解决的问题：** 猜数字游戏输入"你好"会崩溃（ValueError）

**核心概念：**
```python
try:
    可能出错的代码

    出错后的补救方案（程序不再崩溃）
```

**实战过程（三次修复，收获满满）：**
1. safe.py：输入文字提示重试、输入数字正常回显 → 通过

3. guess.py 第二次修复：漏写了 `continue` → 报 NameError（guess 未定义），明白 **接住错误后还要用 continue 把流程送回安全轨道**

### Lesson 06 · 文件读写（已完成 ✅）

**解决的问题：** 程序一关就"失忆"→ 学会永久保存

**核心概念：**
```python
f = open("日记.txt", "a", encoding="utf-8")   # a=追加，w=清空重写，r=只读
f.write(text + "\n")                           # \n 是换行
f.close()                                      # 用完关门

f = open("日记.txt", "r", encoding="utf-8")
lines = f.readlines()                          # 读成列表
```
- `for line in lines:` 遍历列表（for = 数得清的活，while = 满足条件就一直做）
- `len()` 数个数，`strip()` 去掉行尾换行符

**验收记录：** note.py 运行多次，记录从 3 条累积到 4 条，跨运行保存成功 ✅

### Lesson 07 · 记账脚本（已完成 ✅ ｜ 阶段二毕业作品）

**实现方式：** 完全自主设计——AI 助手只给需求清单和两个提示（菜单骨架、split），代码自己组装

**实战中修复的真实 bug（价值连城）：**
1. `f.write(name, money+"\n")` → TypeError：**print 可以逗号喂多个，write 一次只吃一个**，要用加号拼成一个字符串

**最终功能：** 菜单循环（1 记账/2 查账/3 退出）+ 记账金额防弹（try/except + continue）+ 查账防御（跳过坏数据继续统计）+ 明细与总合计

## L8 · 字典与按物品汇总（已完成 ✅ ｜ 2026-10-30）

**解决的问题：** 张双自己提出的"奶茶记了多次、价格不同，怎么自动按物品汇总？"

**核心概念：**
- 字典 = 带标签的柜子：`money_sum = {}`，按**名字**（键）存取：`money_sum["奶茶"] = 25`
- `if name in money_sum:` 判断柜子里有没有这个格子；有则累加，无则新建
- `for name in money_sum:` 遍历字典的每个名字
- `round(x, 1)` 四舍五入到 1 位小数（算平均价用）

**踩过的坑：**
- `mongey_sum` 拼写错误 → "is not defined"（一个字母都不能差）
- 汇总循环里残留旧的明细打印/累加 → **过期变量（stale variable）**：第一个循环结束后 `money` 还是最后一行的值，放进错误的循环就加错账。解决：明细打印和累加搬回"走账本行"的循环，按物品汇总报告单独一段，各司其职

**验收记录（2026-10-30）：** 6 笔明细 + 按物品汇总（奶茶 共 2 笔合计 35 元平均 17.5）+ 总合计，全部正确 ✔

**职业连接：** "按物品归堆求和"就是物资消耗核算的雏形——阶段四的物资核算工具会用同样的思想处理真正的工程台账。

## 今天学到的重要经验

1. **报错不可怕**：读错误信息的最后几行，定位到行号和错误类型。已经打过交道的报错：
   - `can't open file ... No such file or directory` → 文件名打错了（quiz.py11 事件）
   - `ValueError` → 文字转数字失败（guess.py 彩蛋）
2. **改完必须保存**：不保存运行的是旧代码
3. **亲手敲代码**：肌肉记忆比看懂重要
4. **自己改错一次 = 看十个教程**
