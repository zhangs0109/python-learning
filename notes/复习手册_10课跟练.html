一、知识地图：10 节课一张图

L1 · 10-28

输出与输入

  • print() 打印，input() 接收
  • # 注释、代码符号必须英文半角
  • 改完代码要 Cmd+S 再运行
坑：中文标点混入代码 → SyntaxError
L2 · 10-28

变量与三种类型

  • str 文本 / int 整数 / float 小数
  • input() 一律返回 str，算数前要 int()
  • print 里逗号自动加空格；+ 拼接必须都是 str
坑：input 拿到的不转 int 就加减 → 字符串拼接
L3 · 10-28

分支判断

  • if / elif / else 从上往下逐个判
  • == 是比较，= 是赋值
  • 缩进 4 空格是 Python 的语法（不是装饰）
坑：= 与 == 混用；冒号后忘缩进 → IndentationError
L4 · 10-28

循环与随机数

  • while True: + break 退出
  • random.randint(1, 100)
  • 计数器 count = count + 1
坑：死循环 → Ctrl+C 救命
L5 · 10-29

容错 try/except

  • 可能出错的代码放进 try:
  • except: 后要用 continue 接回循环
  • 程序不再被坏输入打崩
坑：只有 except 没有 continue → NameError
L6 · 10-29

文件读写

  • open("日记.txt","a",encoding="utf-8")
  • f.write(...) + f.close()；"a"追加/"w"覆盖/"r"读
  • readlines() 逐行读，strip() 去换行
坑：write() 只收 1 个参数，不能像 print 用逗号
L7 · 10-30

循环统计（记账 v1）

  • for line in lines: 逐行遍历
  • line.split() 按空格切出名称和金额
  • len() 统计、round(x,1) 保留小数
坑：循环内外放错位置 → "过期变量"重复输出；脏数据 → 循环内 try/except 跳过
L8 · 10-30

默写L7 · 读流水文件（每行"名称 金额"），打印明细并算总额 6 分钟
f = open("流水.txt", "r", encoding="utf-8")
lines = f.readlines()
f.close()
total = 0
for line in lines:
    parts = line.split()

    money = int(parts[1])
    print(name, money, "元")
    total = total + money
print("合计", total, "元")
变式L7 · 查询时遇到坏行（金额不是数字）跳过，不崩 4 分钟
    try:

默写L8 · 用字典统计：奶茶 25, 电影票 30, 奶茶 10，按物品汇总 5 分钟
records = [("奶茶", 25), ("电影票", 30), ("奶茶", 10)]
money_sum = {}
for name, money in records:
    if name in money_sum:
        money_sum[name] = money_sum[name] + money
    else:
        money_sum[name] = money
print(money_sum)   # {'奶茶': 35, '电影票': 30}
变式L8 · 同一物品出现不同价格就报警（奶茶：25 和 10） 4 分钟
prices = {}
for name, money in records:
    if name in prices:
        prices[name].append(money)
    else:
        prices[name] = [money]
for name in prices:
    if max(prices[name]) != min(prices[name]):
        print(name, "价格异常：", prices[name])
