一、知识地图：10 节课一张图

L1 · 10-28

输出与输入 print · input

  • print() 打印输出，input() 接收输入
  • # 注释 comment；代码符号必须英文半角 half-width
  • 改完代码要 Cmd+S 保存 save 再运行 run
坑：中文标点混入代码 → SyntaxError（语法错误）
L2 · 10-28

变量与类型 variable · type

  • str 字符串 string / int 整数 integer / float 小数 floating-point
  • input() 一律返回 str，算数前要 int() 或 float() 转换 convert
  • print 里逗号自动加空格；+ 拼接 concatenate 必须都是 str
坑：不转 int 就加减 → TypeError（类型错误）
L3 · 10-28

分支判断 if · elif · else

  • if / elif / else 如果 / 否则如果 / 否则
  • == 比较 compare，= 赋值 assign
  • 缩进 indentation 4 空格是 Python 语法（不是装饰）
坑：忘缩进 → IndentationError（缩进错误）
L4 · 10-28

循环与随机 loop · random

  • while True: 循环 + break 跳出
  • random.randint(1, 100) 随机整数
  • 计数器 counter：count = count + 1
坑：死循环 infinite loop → Ctrl+C 终止
L5 · 10-29

容错处理 try · except

  • 可能出错的代码放进 try: 尝试
  • except: 接住错误 + continue 继续下一轮
  • 程序不再被坏输入打崩 crash
坑：except 后没 continue → NameError（名称错误）
L6 · 10-29

文件读写 file · open · write

  • open("日记.txt","a",encoding="utf-8") 打开
  • "a" 追加 append / "w" 覆盖 write / "r" 读取 read
  • readlines() 逐行读，strip() 去掉首尾空白
坑：write() 只收 1 个参数 argument，不能像 print 用逗号
L7 · 10-30

循环统计 for · split · len

  • for line in lines: 遍历 iterate 每一行
  • line.split() 按空格切分 split 出名称和金额
  • len() 长度 length、round(x,1) 四舍五入
坑："过期变量" stale variable；脏数据 dirty data → 循环内 try/except 跳过 skip
L8 · 10-30

字典 dict · dictionary

  • money_sum = {} 建空字典、name in dict 查键 key 存在
  • 核心套路：有就累加 accumulate，没有就新建 create
  • 延伸：max() 最大 / min() 最小 找价差
坑：变量名拼错 typo → 看 Problems（问题）面板
L9 · 11-01

Git 本地 add · commit

  • 三区：工作区 working → 暂存区 staging → 仓库 repository
  • git status 状态 / diff 差异 / log 日志
  • "没输出 = 成功"的 Unix 哲学
坑：配置后必验证 verify；add . 只管当前目录，全仓库用 add -A
L10 · 11-01

GitHub 远程 remote · push · pull

  • commit 本地存档，push 推送上云，pull 拉取回来
  • 日常三部曲：add → commit → push
  • VS Code OAuth 授权 authorize 免配置密钥
坑：Public 公开 / Private 私有 可见性；不用的 PAT（个人令牌）要吊销

默写L7 · 读流水文件（每行"名称 金额"），打印明细并算总额 6 分钟
f = open("流水.txt", "r", encoding="utf-8")
lines = f.readlines()
f.close()
total = 0
for line in lines:
    parts = line.split()
    name = parts[0]
    money = int(parts[1])
    print(name, money, "元")
    total = total + money
print("合计", total, "元")
变式L7 · 查询时遇到坏行（金额不是数字）跳过 skip，不崩 4 分钟

默写L8 · 用字典 dict 统计：奶茶 25, 电影票 30, 奶茶 10，按物品汇总 5 分钟
records = [("奶茶", 25), ("电影票", 30), ("奶茶", 10)]
money_sum = {}
for name, money in records:
    if name in money_sum:
        money_sum[name] = money_sum[name] + money
    else:
        money_sum[name] = money
print(money_sum)   # {'奶茶': 35, '电影票': 30}
变式L8 · 同一物品出现不同价格就报警（奶茶：25 和 10） 4 分钟
prices = {}
for name, money in records:
    if name in prices:
        prices[name].append(money)
    else:
        prices[name] = [money]
for name in prices:
    if max(prices[name]) != min(prices[name]):
        print(name, "价格异常：", prices[name])
